# 造神计划

一个可独立安装到手机使用的六周成长计划 PWA。数据只保存在当前浏览器中，无需账号。

## 本地运行

在此文件夹打开终端，运行：

```powershell
node dev-server.js
```

电脑浏览器访问 `http://127.0.0.1:4173`。手机与电脑连接同一个 Wi-Fi 后，访问终端显示的“手机访问”地址。

局域网 HTTP 地址可以直接使用并保存数据。要使用完整离线能力并稳定添加到手机主屏幕，需要将项目部署到 HTTPS 地址。

运行完整自动测试：

```powershell
npm test
```

生成正式发布文件：

```powershell
npm run build
```

## 已有功能

- 创建并基础编辑固定六周计划
- 根据日期和执行日自动生成今日任务
- 每日任务打卡、今日进度与连续完成天数
- 六周路线和当前阶段状态
- 每日复盘自动保存，填写任意内容后自动完成复盘任务
- 月度打卡日历、执行天数和各目标完成率
- 重新开始、归档当前计划与清除全部数据
- 离线打开和添加到主屏幕
- 数据备份导出、验证和恢复
- 在线状态与新版本更新提示

## 数据说明

- 所有计划、打卡和复盘保存在浏览器的 `localStorage`。
- 清理浏览器网站数据会删除记录。
- 换手机或清理数据前，请先在“我的”页面导出备份。
- “我的”页面中的“清除全部数据”需要二次确认。

## GitHub Pages

项目包含 `.github/workflows/pages.yml`。推送到 `main` 分支后会自动运行测试、构建并发布到 GitHub Pages。
